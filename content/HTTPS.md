# HTTPS

## Как HTTPS шифрует данные?

HTTPS использует шифрование SSL (Secure Sockets Layer) или его более современную версию TLS (Transport Layer Security) для защиты передаваемых данных. SSL / TLS работает по принципу симметричного и асимметричного шифрования, используя сертификаты цифровой подписи, чтобы обеспечить конфиденциальность, целостность и подтверждение подлинности данных.

При установке безопасного соединения HTTPS между клиентом (например, браузером) и сервером SSL / TLS устанавливает «защищённый туннель», через который будут передаваться данные. Для этого происходит следующее:

1. Клиент, который запрашивает защищённое соединение, отправляет запрос на сервер.
2. Сервер, который поддерживает SSL / TLS, отвечает, отправляя свой сертификат на клиент. Этот сертификат содержит открытый ключ сервера и информацию об удостоверяющем центре (CA).
3. Клиент проверяет, что сервер является доверенным (т.е. проверяет, что идентификатор сервера, указанный в его сертификате, соответствует ожидаемому идентификатору, а также что сертификат был выпущен удостоверяющим центром, которому доверяет клиент).
4. После проверки клиент генерирует случайный секретный ключ (symmetric key), который будет использоваться для шифрования данных на данном соединении.
5. Клиент использует открытый ключ сервера, содержащийся в его сертификате, для шифрования секретного ключа, который он только что сгенерировал.
6. Клиент отсылает зашифрованный секретный ключ серверу.
7. Сервер расшифровывает секретный ключ при помощи своего собственного закрытого ключа (private key), который соответствует открытому ключу, хранящемуся в его сертификате.

Теперь, когда у клиента и сервера есть общий секретный ключ, который используется для шифрования и дешифрования данных, они могут передавать данные друг другу через защищённый туннель. Это делает HTTPS одним из самых безопасных способов передачи данных через Интернет.
